# Code of Conduct

Kelp follows the [Contributor Covenant 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be kind and constructive, assume good intent, and keep discussion about the work. Harassment, insults and
personal attacks are not welcome in issues, pull requests or anywhere else in the project.

Report unacceptable behavior privately to the maintainer through GitHub (@nikiomori). Reports are kept confidential;
the maintainer may edit or remove comments, close threads, or block people who break these rules.
